# Security Policy

## Supported versions

Only the latest release on PyPI receives fixes.

## Reporting a problem

Open a GitHub Issue on this repository, or email <wookjin.choi@jefferson.edu> for anything you
would rather not post publicly. Include the affected version, a minimal reproduction and the
impact you see. Fixes ship as a new release and are credited in [CHANGELOG.md](CHANGELOG.md)
unless you ask otherwise.

Never include real API keys or patient data in a report.
